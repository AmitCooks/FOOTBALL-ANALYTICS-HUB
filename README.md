# ⚽ Football Player Performance Analytics Dashboard

> **Disclaimer:** All data in this project is **synthetic and for demonstration purposes only.**
> It does not represent real-world football players, clubs, or match results.

An interactive, portfolio-quality football analytics dashboard built with **Python**, **Streamlit**,
**Pandas**, **NumPy**, and **Plotly**.

---

## 📸 Features

| Page | What you get |
|---|---|
| **Overview** | 5 KPI cards · Top 10 leaderboard · Searchable stats table · CSV download |
| **Player Analysis** | Side-by-side player comparison · Goals vs Assists scatter · Shots vs Goals scatter |
| **Team Analysis** | Grouped goals/assists bar · Player count bar · Team summary table |
| **Position Analysis** | Per-position KPI cards · Avg goals bar · Avg rating bar · Rating box plot |

**Shared Sidebar Filters:** Season → Team → Position → Player (cascading)

## 📊 Dataset Schema

File: `football_players.csv` — generated by `data_generator.py` using `numpy.random.seed(42)`.

| Column | Type | Description |
|---|---|---|
| `player_id` | int | Unique row identifier |
| `player_name` | str | Full name (fictional) |
| `team` | str | One of 8 fictional clubs |
| `position` | str | GK / DEF / MID / FWD |
| `season` | str | 2022/23 · 2023/24 · 2024/25 |
| `age` | int | Player age |
| `matches_played` | int | Matches in that season |
| `minutes_played` | int | Total minutes |
| `goals` | int | Goals scored |
| `assists` | int | Assists |
| `shots` | int | Total shots |
| `pass_accuracy` | float | Pass accuracy % |
| `dribbles` | int | Successful dribbles |
| `yellow_cards` | int | Yellow cards |
| `red_cards` | int | Red cards |
| `rating` | float | Computed rating (5.0 – 9.5) |

**Rating formula:** `0.4 × (goals) + 0.3 × (assists) + 0.2 × (pass_accuracy) + 0.1 × (minutes)` — all normalised then scaled to 5.0–9.5.

## 🚀 Run Locally

### 1. Clone / download

```bash
git clone https://github.com/your-username/football-analytics-hub.git
cd football-analytics-hub
```

### 2. Create a virtual environment (recommended)

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. (Optional) Regenerate the dataset

```bash
python data_generator.py
```

### 5. Launch the app

```bash
streamlit run app.py
```

The app opens automatically at **http://localhost:8501**.

---

## ☁️ Deploy to Streamlit Community Cloud

1. Push this repository to **GitHub** (make sure `football_players.csv` is committed).
2. Go to [share.streamlit.io](https://share.streamlit.io) and sign in with GitHub.
3. Click **New app**.
4. Select your repository, branch (`main`), and set the **Main file path** to `app.py`.
5. Click **Deploy** — no secrets or environment variables are required.

---

## 🛠️ Regenerating the Dataset

If you want to customise the clubs, player counts, or stat weights:

1. Edit the constants at the top of `data_generator.py` (`CLUBS`, `SQUAD_SIZE`, `STAT_WEIGHTS`, etc.).
2. Run `python data_generator.py` — this overwrites `football_players.csv`.
3. Restart the Streamlit app (it caches the CSV; press **R** in the browser or restart the server).
